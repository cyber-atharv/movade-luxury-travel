## ✨ Features

- **🌐 Interactive 3D Travel Network**: Real-time dotted 3D world map showing flight networks and global travel hotspots.
- **🎥 3D Depth Scenes & Parallax Galleries**: Scroll-triggered camera shifts and multi-layered perspective imagery.
- **⚡ Ultra-Smooth Momentum Scrolling**: Integrated Lenis scroll physics for responsive navigation.
- **🔍 Intelligent Destination Finder**: Curated search widgets with instant spot previews and price cards.
- **📱 Fully Responsive**: Fluid layouts engineered for desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Export)
- **3D & Canvas**: [React Three Fiber](https://docs.pmnd.rs/react-three-fiber), [Drei](https://github.com/pmndrs/drei), [Three.js](https://threejs.org/)
- **Animations**: [GSAP](https://greensock.com/gsap/), [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/cyber-atharv/movade-luxury-travel.git
   cd movade-luxury-travel
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
